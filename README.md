# Workout & Exercise REST API

A Flask-based RESTful API backend for tracking workouts, exercises, and their relationships with built-in data validation and serialization using Marshmallow and SQLAlchemy.

## Technologies Used
- Python 3.8+
- Flask 2.2.2
- Flask-SQLAlchemy 3.0.3
- Flask-Migrate 3.1.0
- Marshmallow 3.20.1
- SQLite

## Installation Instructions
1. Clone the repository and navigate into the project root directory.
2. Install dependencies using Pipenv:
   ```bash
   pipenv install
   pipenv shell
